# Data and code availability — final submission wording

The complete submission-primary reproducibility package is provided as Supplementary Material with the manuscript. It contains the source/configuration snapshot, submission-primary experiment manifest, the seed-level 10,800-run evidence ledger, analysis and validation scripts, generated evidence tables, claim-evidence mapping, and the reproducibility audit. The submitted archive is `SWEVO_FINAL_REPRODUCIBILITY_SUPPLEMENT_2026-09-03.zip`; its SHA-256 checksum is `3aad983271e0e1cb6e7b4c62e38949906861ccf156b6e74722b6d500b6576a95`.

A public GitHub submission-scope mirror is maintained at the `submission-2026-09-02` branch of `ErcanErkalkan/swevo_strat2_realcode`. A release-style frozen branch ref, `release/v0.2.0-submission-rc1`, points to the finalized submission metadata state. The supplementary archive, rather than historical generated outputs in older repository history, is the authoritative evidence snapshot for the submitted manuscript. Historical A1/A2/A3 exploratory runs are excluded from submission-primary inference.

The production campaign was executed on a Dell Vostro 3888 with an Intel Core i5-10400 CPU (6 cores/12 threads, 2.90 GHz), 16 GB RAM (2×8 GB at 2400 MHz), integrated Intel UHD Graphics 630, and Windows 11 Enterprise 64-bit build 26200. Storage comprised a 256 GB SK hynix NVMe SSD and a 480 GB Toshiba TR200 SATA SSD; BIOS version was Dell 2.35.1 and the motherboard identifier was Dell 0RM5DR. The optimizer is CPU-based and did not use the integrated GPU for search computation. The run ledger does not embed a per-run hardware fingerprint, and electrical power was not measured with hardware counters. Accordingly, runtime comparisons are scoped to the documented workstation/protocol and `compute_wh` remains a model-based runtime proxy rather than hardware-metered electrical energy.
